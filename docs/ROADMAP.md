## v1.3 — 检索质量（规划中）

## 已知限制（诚实清单）

| 限制 | 现状 | 规避方式 |
|---|---|---|
| 关键词打分无全局 IDF | 内存态索引的取舍 | RRF + 重排补偿，见 FAQ |
| 固定窗口限流有 2 倍窗口边界突发 | 简单实现的取舍 | 保护 LLM 场景够用；更平滑可换 Redis Cell |
| 评估集为 11 科室手工样例 | 非大规模基准 | `evaluation/` 脚本可换自建数据集 |
| 语音识别依赖外部 WS 服务 | 未内置 ASR 模型 | 可对接 FunASR/Whisper 服务 |
